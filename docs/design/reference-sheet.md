# FRONTIER reference sheet

This is a pattern reference sheet, not a source of copied content or assets.

| Reference | Take | Do not take |
|---|---|---|
| Nothin' | disciplined monochrome typography | brand, copy, or code |
| Igloo Inc | one familiar gesture drives the experience | inaccessible 3D complexity |
| Vectura | clear dual actions and named contacts | background video without controls |
| Trustly travel | short benefit headline and proof strip | invented partner logos or counts |
| Phenomenon Studio | senior ownership and clear positioning | unsupported credentials |
| Ontiver | honest launch copy and skip link | copied identity or legal claims |
| QuickBite | numbered steps, real figures, reduced-motion loader | fake food metrics or copied visuals |
| NEAR game references | on-chain state as the visible game world | claims beyond the deployed contract |

## Decisions

- FRONTIER is a live testnet tool, not a marketing landing page.
- The map and contract state are the first-viewport signal.
- The design uses existing FRONTIER tokens and no effects library.
- New imagery is not required for the map-first game surface.
