# Gaming copy overrides: FRONTIER

Use in-world language with concrete mechanics. Facts stay plain: testnet, current contract, route distance, stake, cargo, and future systems. Avoid `epic`, `next-gen`, `ultimate`, `revolutionary`, and claims of AI or cross-chain behavior that is not live.

## Preferred copy

- `Connect wallet`
- `Register player`
- `Buy cargo`
- `Build a sloop`
- `Depart with sealed destination`
- `Commit ambush`
- `Reveal ambush`
- `Arrive`
- `Download salt backup`

Use `Guided tutorial` for the local walkthrough. Use `Scripted rivals` only when a server or runner is actually moving rival accounts. Result feed copy names the transaction outcome and the next action.
