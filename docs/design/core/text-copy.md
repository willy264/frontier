# Text and copy standard

- Say what the interface does in concrete verbs: `Buy cargo`, `Reveal ambush`, `Arrive`.
- State uncertainty plainly: `Read-only mode`, `Testnet contract state`, `Future work`.
- Never claim profit, AI rivals, mainnet, cross-chain settlement, storms, seasons, or port sub-accounts unless the current evidence proves it.
- Prefer numbered steps for a process. Keep each step to one action.
- Error copy states what failed and the next recovery action.
- Avoid lorem ipsum, fake metrics, fake names, fake logos, and invented testimonials.
- Do not use em dashes in UI copy.
- Reference material informs patterns only. Never copy its text, logos, illustrations, or code.
