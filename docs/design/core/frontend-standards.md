# Frontend standards

- Use semantic HTML and keyboard-accessible controls.
- Give icon-only controls an accessible name and tooltip where the icon is unfamiliar.
- Keep focus visible and never hide it behind a custom outline reset.
- Make interactive targets at least 44x44px where practical and never below 24x24px.
- Provide hover, focus-visible, active, disabled, pending, success, and error states.
- Use descriptive alt text for meaningful images. Give fixed media dimensions or aspect ratio, use AVIF/WebP where applicable, and lazy-load below-the-fold media.
- Keep loading states stable so content does not shift.
- Respect reduced motion and avoid layout animation.
- Test keyboard navigation, 200% zoom, narrow widths, and read-only RPC failure.
