# Motion / creative studio: copy overrides

Applies on top of `core/text-copy.md`.

## 1. Register

Statement-led and minimal. Lowercase allowed. Let the work speak; the copy states a point of view. [SYN from 3P: noth.in]

| Slot | Rule | Example |
|---|---|---|
| H1 | What and where, plainly | "Creative studio in Paris." [3P: noth.in] |
| Statement H2 | One point of view per line; a contrast is fine if both halves are concrete | "Most brands produce content. We prefer ideas." [3P: noth.in] |
| Labels | Authored, bracketed, consistent | "( The Studio )", "( The step aside )" [3P: noth.in] |
| CTA | Lowercase allowed, verb-first | "book a call" [3P: noth.in] |
| Project titles | Client + one-line what | |
| Sign-off | One line with the studio's voice | "Let's start from nothin'" [3P: noth.in] |

## 2. Watch the tells

Studio copy drifts into the humanizer list faster than any other niche. Check each statement:

| Tell | Example to avoid | Fix |
|---|---|---|
| Fake-deep saying | "At its core, design is a conversation." | Say what you do: "We design launch films and websites for product teams." |
| Not-X-but-Y on every line | "Not a style, a perspective." used three times | Keep at most one per page |
| Slogan pair with no claim | "Designs That Speak. Brands That Shine." [3P: Palletio] | Name the work and the client type |
| False range | "From startups to global brands" | Name two real clients (with permission) |
| Inflated words | "elevate", "craft experiences", "push boundaries" | Concrete nouns: films, sites, identities |

noth.in's "Not a style, a perspective." is itself a not-X-but-Y line. It works once, as the studio's thesis. Do not copy the construction.

## 3. Case-study copy

| Slot | Rule |
|---|---|
| Title | Client: project type |
| One line | What the project had to do |
| Credits | Roles, collaborators, year |
| Outcome | A real result if there is one; otherwise leave it out |
