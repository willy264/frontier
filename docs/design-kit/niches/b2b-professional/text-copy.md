# Professional B2B: copy overrides

Applies on top of `core/text-copy.md`.

## 1. Register

Capability statements and metric-headline case studies. Specific, unhurried, no hype. [SYN]

| Do | Don't |
|---|---|
| "Approve invoices in Slack. Sync to Xero when they're paid." | "Supercharge your finance workflow" |
| "Cut close time from 9 to 3 days" (case-study headline with source) | "Unlock efficiency at scale" |
| "SOC 2 Type II report available on request" (only if true) | "Enterprise-grade security" |
| "Design and engineering partner for scaling and regulated companies" [3P: Phenomenon] | "We build the future of work" |
| "We design for implementation, not handoff." [3P: Phenomenon] | Generic "Our process" with icon triplets |

The Phenomenon line uses a "not X" contrast. It works because both halves are concrete. Use the pattern at most once per page.

## 2. Headlines

- Name the product category and the outcome in the H1. Fragment pairs are allowed if each fragment is a claim: "Verify people. / Connect every step." [OWN: Ontiver enterprise]
- Eyebrows optional. If used, they name the section, not the vibe.

## 3. CTAs

| Role | Examples |
|---|---|
| Primary | "Get a demo", "Start sandbox", "Request enterprise demo" [OWN], "Start free trial" |
| Secondary | "Talk to sales", "See pricing", "Explore platform" [OWN] |
| Services | A single "Book a call" |

## 4. Product microcopy

| Situation | Pattern | Example [SYN] |
|---|---|---|
| Empty table | What appears + primary action | "No invoices yet. Create an invoice or import a CSV." |
| No results (filtered) | Say it's the filter + clear | "No invoices match these filters. Clear filters." |
| Permission denied | Who can do it | "Only admins can change billing. Ask an admin on your team." |
| Bulk success | Count + past tense | "12 invoices archived. Undo" |
| Export started | What and where | "Your CSV is being prepared. We'll email it to <email> when it's ready." |
| Destructive confirm | Name the object + consequence | Title: "Delete workspace?" Body: "This deletes 4 projects and 312 files for everyone. It can't be undone." Buttons: "Delete workspace" / "Cancel" |
| Validation | Specific | "Enter a work email, for example name@company.com." |
| Saved | Mirror verb | "Changes saved" |

## 5. Case-study template

| Slot | Rule |
|---|---|
| Headline | The metric, with timeframe ("from 9 to 3 days in one quarter") |
| Client | Named, with consent |
| Problem | One paragraph |
| What we did | 3–5 concrete actions |
| Result | The metric again with source; one quote with name and role |
